# Performance projects

- [`benchmark`](benchmark) is the deterministic iOverlay, xOverlay, and Boost
  Polygon 90 comparison, including its generated report page.
- [`random_test`](random_test) is an independent randomized test project and is
  intentionally not part of the deterministic benchmark workflow.

See the [benchmark usage guide](benchmark/README.md) for build, run, JSON, SVG,
and report generation commands.
